# ⚡ TIC-TAC-TOON | Modern Duel Arena

![Game Screenshot](https://via.placeholder.com/800x400?text=Tic+Tac+Toon+Game)

A premium, responsive Tic Tac Toe game with **dark/light theme**, **player customization**, **celebration animations**, and a sleek glassmorphism UI. Built with pure HTML, CSS, and JavaScript.

## 🎯 How to Play

1. **Enter Names** - Both players type their warrior names
2. **Choose Symbols** - Pick X or O (must be different)
3. **Start Battle** - Click "START BATTLE" to begin
4. **Take Turns** - Click on any empty cell to place your symbol
5. **Win Condition** - Get 3 in a row (horizontal, vertical, or diagonal)
6. **Celebration** - Winner gets a confetti celebration!
